# data/

Output of the daily pipeline. Files here are generated by GitHub Actions - do not edit by hand.

Planned contents:
- `status.json` - last run heartbeat
- `universe.json` - NSE stocks with F&O flag, sector, market-cap bucket (Phase 2)
- `ohlcv/<SYMBOL>.json` - daily candles per stock (Phase 2)
- `signals/` - daily scores and picks (Phase 4+)
